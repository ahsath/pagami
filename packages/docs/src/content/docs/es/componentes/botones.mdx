# Botones

Los botones son una implementación solo con CSS que permite al usuario realizar acciones concretas. Hay cinco variantes (relleno, tonal, elevado, delineado y texto) y dos tamaños; añade la clase `button` a elementos interactivos nativos para aplicar los estilos de botones.

## [Uso](#uso)

Para crear un botón, añade la clase `button` a cualquier elemento interactivo nativo. El tipo por defecto del botón es texto.

<div class="preview-dots">
  <button class="button">Botón</button>
  <a href="#" class="button">
    <span>Link</span>
  </a>
</div>

## [Iconos](#iconos)

Los iconos deben colocarse en la parte delantera, antes del texto.

<div class="preview-dots">
  <button class="button button--filled">
    <SendRounded />
    <span>Enviar</span>
  </button>
</div>

```html
<button class="button button--filled">
  <svg aria-hidden="true"><!-- ... --></svg>
  Enviar
</button>
```

## [Deshabilitado](#deshabilitado)

  </button>

## [Modo oscuro](#modo-oscuro)

El modo oscuro se activa automáticamente si el usuario tiene el modo oscuro habilitado en su sistema operativo, no es necesario agregar ninguna clase adicional.

Por hacer: Agregar un interruptor a nivel de sitio para que el usuario pueda alternar desde aquí directamente y no desde un menú oculto en algún lugar.

## [Indicadores de carga](#indicadores-de-carga)

Si quieres ocultar el icono mientras se muestra el indicador de carga, asegurate de aplicar el atributo `aria-busy` al botón y la clase `button__icon` al icono (`svg` o cualquier otro). De lo contrario, ambos son opcionales, aunque siempre se recomienda aplicar el atributo `aria-busy` para garantizar la accesibilidad.

### [Transformación de formas (Morphing)](#transformación-de-formas)

Disponible como componente, este indicador alterna entre 7 formas `svg` diferentes; es extremadamente pesado, no lo usaría si me importara el peso final de mi aplicación.

<div class="preview-dots">
  <MorphingIndicator />
</div>

```vue
<script lang="ts" setup>
import { ref } from "vue";
import { LoadingIndicator } from "@pagami/vuei";

const busy = ref(false);
</script>

<template>
  <button
    class="button button--filled button--size-m"
    :aria-busy="busy"
    @click="busy = true"
  >
    <LoadingIndicator aria-hidden="true" />
    <!-- Icono (opcional) -->
    <svg class="button__icon" aria-hidden="true"><!-- ... --></svg>
    {{ busy ? "Cargando" : "Haz click en mi!" }}
  </button>
</template>
```

      Evita deshabilitar botones con el atributo `aria-busy`, los navegadores
      eliminan los botones deshabilitados del orden de tabulación del teclado y
      del árbol de accesibilidad, es mejor usar `aria-disabled="true"` (por el

      predeterminada con `preventDefault`.
      <br />
      Utiliza el atributo `aria-hidden="true"` para ocultar los iconos de los
      lectores de pantalla, a menos que el icono transmita información
      importante que no se encuentra en el texto del botón. En ese caso,
      asegúrate de proporcionar una descripción accesible utilizando
      `aria-label` o `aria-labelledby` en el botón.
    </div>
