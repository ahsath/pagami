# Botones

Los botones permiten realizar acciones, como enviar un correo, compartir un documento o dar "me gusta". Aplica estas clases CSS a elementos `<button>` o `<a>` para integrar los estilos de Google Material 3, desde botones rellenos de énfasis alto hasta variantes de texto de énfasis bajo.

## Referencia rápida

## [Uso](#uso)

Para crear un botón, añade la clase `button` a cualquier elemento interactivo nativo. El estilo por defecto del botón es texto.

{/* prettier-ignore */}
```html
<button class="button">Botón</button>
<a href="#" class="button">Link</a>
```

```typescript
const button = document.querySelector(".button");
button.addEventListener("click", () => {
  alert("¡Botón clickeado!");
});
```
